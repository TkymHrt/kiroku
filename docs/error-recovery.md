# エラー表示と復旧導線（2026-10-18）

何に失敗し、本文がどこに残り、次に何を押せばよいかを同じ場所で示す。ブラウザ例外やAPIの技術的メッセージをそのまま表示しない。

| 状況                   | 案内・操作                                                                                    |
| ---------------------- | --------------------------------------------------------------------------------------------- |
| 初期接続失敗           | 接続確認と「もう一度接続する」                                                                |
| 一覧取得失敗           | 「一覧を読み直す」。空一覧として表示しない                                                    |
| 日記取得失敗           | 「日記を読み直す」。未取得を保存済み/記録なしと断定せず、端末本文を出す場合は最新未確認と示す |
| サーバー保存失敗       | 端末に本文が残ることと自動再試行を説明。「保存を再試行」、本文コピー・Markdown保存            |
| 端末保存失敗・容量不足 | 閉じるリスクを示し、先頭に本文コピー・Markdown保存。退避後に端末保存を再試行                  |
| 認証切れ               | 別タブでログインし、元の画面で保存を再開                                                      |
| 競合                   | 両本文を確認して採用・統合。自動上書きしない                                                  |
| 一括出力失敗           | 「もう一度エクスポート」で出力自体を再実行                                                    |
| 上限超過・長期未同期   | 注意のそばに本文コピー・Markdown保存                                                          |

通常の手動読込は待機を解除して再実行する。HTTPのRetry-Afterは維持し、期限までボタンを無効にして理由を表示する。期限後は自動で有効に戻す。再試行で競合や入力不正を上書きしない。

## コピーと診断情報

本文コピーと「エラー情報をコピー」は対象・成功通知・手動コピー画面を分ける。自動コピーを拒否された場合は、読み取り専用欄と「すべて選択」を使えるようにする。コピー成功を保存成功にせず、警告も消さない。

診断に含めるのはアプリ名・操作名・許可した分類コード・取得できたHTTP状態・コピー時刻・固定タイトルだけ。本文、URL、メール、認証情報、生の例外・スタックは含めない。
