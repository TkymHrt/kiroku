## 2026-10-18の変更

| 問題                                   | 変更                                                                                     |
| -------------------------------------- | ---------------------------------------------------------------------------------------- |
| タイトル・説明・ナビが現在地を繰り返す | 重複バーと大きな導入を削除。選択ナビとaria-currentで示し、読み上げ用見出しは残した       |
| 編集上部の操作が縦に積まれる           | 戻る・日付・記録済み前後・保存状態を1ヘッダーに統合                                      |
| 日付形式と余白がブラウザ依存           | 手入力を廃止し、YYYY/MM/DDと年/月選択・日付タップに変更。選択後すぐ開く                  |
| ゴミ箱から通常日記も開ける             | 日付移動を外し、復元と必要時の説明に絞った                                               |
| 一覧内の日付が重複する                 | 月見出し・日番号・曜日・保存状態に整理。アクセシブル名は完全な日付                       |
| 装飾と定型文が場所を取る               | ロゴ横アイコン・タグライン・大きな空状態アイコンを削除。空状態は実用的な短文と操作にした |

配色、本文文字サイズ、保存状態の区別、警告、本文退避は維持した。通常の保存説明は設定へ移した。

日付選択は表示年の前後100年をメニューにし、選択後に範囲を更新する。対応日をその範囲に制限するものではない。Escape・キャンセルで本文と対象日を保持し、矢印/Home/End/PageUp/Downと起動ボタンへのフォーカス復帰に対応した。月間日記カレンダー画面は追加していない。

英語設定でも年先頭表示、390px/360pxでの重なりや横スクロールなしを確認した。独立レビューは10画像とソースで必須修正なし。空状態の6画面も確認し、読取スモークではPOST0件・空日未作成だった。

## 2026-10-19の変更

700px以下のナビを画面端から端まで隙間なく3等分し、背景・下線・押下範囲も各1/3に揃えた。中央揃え・高さ44px以上、ロゴと今日の左右余白20pxを維持し、端のフォーカス枠は3px内側にした。

年/月のnative selectは矢印を右12px、文字の右余白36pxにした。最小幅は年96px/月78px、360px以下は内側余白12px・間隔4pxで320pxに収めた。footerは「今日」だけにした。

一覧・編集・カレンダーの曜日色を平日 #58715c、日曜 #98615e、土曜 #526f86で共通化した。白/通常背景のコントラストは4.60:1以上で、曜日文字も残した。

remark-breaksでEnter1回をプレビューの改行として表示する。段落・GFMリスト・チェック・コードの構造は維持し、保存・コピー・Markdown出力のソース本文は変更しない。

単体91件・Workers4件・型・build・E2E40件と、フォーカス調整後の関連2件が成功した。320px/390pxの寸法・タップ範囲・選択欄の収まりを確認し、独立レビューも必須修正なし。本番の読取確認は [公開記録](deployment.md) を参照する。

画面と実測は開発端末の `.impeccable/review/ui-refine/`・`empty-refine/` に保管し、Git管理対象外。いずれもPC上の検証で、Android実機のIME等は未確認。
